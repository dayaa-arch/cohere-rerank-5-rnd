# フェーズ2（評価データ）報告

国税庁タックスアンサーの源泉所得税65項目から345チャンクを作り、質問案40問と正解ラベル案を付けた。API呼び出しは行っていない。

確認してほしいのは次の3点。

1. 40問すべての質問文と正解ラベル。一覧は [phase2_qa_review.md](phase2_qa_review.md) にあり、正解チャンクの本文を並べてある。直すときは `data/qa.jsonl` を直す。
2. 正解ラベルを2段階（正解・部分正解）にしてよいか（§3）。
3. 判断に迷った問題（§4）の扱い。

## 1. コーパスとチャンク

| 項目 | 値 |
| --- | --- |
| 文書 | 65ページ（タックスアンサーの「源泉所得税」分野すべて。令和8年4月1日現在法令等） |
| 本文 | 80,540字（取り出したあと） |
| チャンク | 345件。長さは最短29字、中央値280字、最長515字（先頭行の「ページ名｜見出し」を含む） |
| 1ページあたり | 1〜23チャンク。最多は No.2741（退職手当等が複数ある場合）の23 |

チャンクの分け方は次のとおりで、全条件で同じものを使う。

- 見出し（h2・h3）の節をまたがない
- 節の中の段落・箇条・表の行を、400字を超えない範囲で順に詰める。400字を超える段落は句点の直後で切る
- 節の最後のチャンクが80字未満なら、480字以内に収まる場合に限り直前のチャンクにまとめる
- 先頭行に「ページ名｜見出し」を付ける。どのリランカーにも同じ文字列を渡す

本文から外したのは「対象税目」「根拠法令等」「関連リンク」「関連コード」「QAリンク」「お問い合わせ先」の節。表は1行ずつ「セル | セル」の文に直した。No.2517 の算式は画像のため取り込めていない。

HTMLの一部に閉じタグのない `<p>` があり、最初の抽出では段落が入れ子になって本文が重複していた。HTML5の規則どおりに段落を閉じるパーサー（lxml）に替えて直した。

## 2. 質問案40問

| 種類 | 問数 | 作り方 |
| --- | --- | --- |
| 素直な事実検索 | 12 | 本文の言葉をそのまま使った |
| 言い換え | 12 | 「社員旅行」「ランチ代」「副業先」「ライセンス料」のように、本文にない日常の言葉で聞いた |
| 複数箇所にまたがる | 8 | 答えに2チャンク以上が要る問題。6問は同じページ内の2チャンク、2問は別々のページ（q25は弁護士報酬と外交員報酬、q29は電車通勤とマイカー通勤） |
| 答えがコーパスにない | 8 | 住民税の特別徴収、給与支払報告書、法定調書合計表、不納付加算税、社会保険の加入基準、延滞税、副業20万円の確定申告、マイナンバーの本人確認 |

答えがない8問は、使った語句がコーパスにないことを検索で確かめた。ただし q36（不納付加算税）は、No.2889 に「加算税等の附帯税は還付されない」という一文がある。q39（副業20万円）は「20万円」「確定申告」という語が別の文脈で出てくる。どちらも、しきい値の確認で紛らわしい候補になるので残した。

言い換えの問題が本当に本文と違う言葉になっているかを、質問文の2文字の並び（ひらがなだけの組は除く）が正解チャンクに含まれる割合で確かめた。

| 種類 | 平均 | 範囲 |
| --- | --- | --- |
| 素直な事実検索 | 0.79 | 0.57〜0.97 |
| 言い換え | 0.26 | 0.09〜0.44 |
| 複数箇所にまたがる | 0.64 | 0.50〜0.78 |

最初の案では q20（短期アルバイト）が0.68と高かったので、「日給」「税額表」を使わない言い方に直した（0.36）。

## 3. 正解ラベルの2段階

仕様書の「必要なら関連度を2段階」に沿って、`data/qa.jsonl` に2種類のラベルを付けた。

- `relevant_chunk_ids`（正解）：答えを含むチャンク。Recall@5、MRR、nDCG（関連度2）に使う
- `partial_chunk_ids`（部分正解）：答えの一部や、別の文脈で同じ規則を書いたチャンク。nDCG（関連度1）にだけ使う

2段階にしたのは、同じ規則が複数のページに出てくるからだ。たとえば「納期の特例では1〜6月分を7月10日に納める」は、No.2505（納期の特例）のほか、弁護士報酬（No.2798）と司法書士報酬（No.2801）のページにも書かれている。q01では No.2505 を正解、残りを部分正解にした。1段階にまとめる場合は、部分正解を消すか正解に移せばよい。

`answer` 欄には、確認用に想定回答を書いた。指標の計算には使わない。

## 4. 判断に迷った問題

| 問題 | 迷った点 |
| --- | --- |
| q14 ライセンス料 | 「ソフトウェアのライセンス料」を「著作権等の使用料（20.42％）」に当たるとしたのは筆者の判断で、コーパスにソフトウェアという語はない。言い換えとしては強すぎるかもしれない |
| q18 子どもの学費 | 社員の子どもは「特別の関係がある者（使用人の親族）」に当たるので原則課税、ただし例外あり、と読んだ。答えが2チャンクにまたがるので、複数箇所の問題に移す手もある |
| q22 退職後の残業代 | 原則の乙欄（No.2739-01）と例外の甲欄（No.2739-02）の両方を正解にした |
| q26 勤続25年の退職金 | 控除額1,150万円は、チャンクにある算式から筆者が計算した値で、本文には書かれていない |
| q36・q39 | 答えはないが近い語句がある（§2） |
